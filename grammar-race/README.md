# سباق النحو

لعبة سباق تعليمية لقواعد النحو (المرحلة الإعدادية): يختار الطالب السائق والدرس، ثم يقود السيارة نحو خط النهاية ويمرّ بخمس بوابات أسئلة.

- الإجابة الصحيحة: إشارة إنجاز، ونيترو، ويقصر الطريق 450 م.
- الإجابة الخاطئة: إشارة تحويلة، وشرح للإجابة الصحيحة، ويطول الطريق 450 م.
- 17 درسًا ومراجعة شاملة، وفي كل درس 8–10 أسئلة يُختار منها 5 عشوائيًا في كل سباق.

افتح `index.html` في المتصفح مباشرة. ملف واحد بلا خادم، وكل الرسومات مرسومة بالكود.
التحكم: الأسهم أو أزرار الشاشة للتوجيه، والأرقام 1–4 للإجابة.
